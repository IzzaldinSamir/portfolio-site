# Security Policy

## Supported Versions

Only the latest deployment tracking the `main` branch is actively maintained with security updates.

| Version / Branch | Supported          |
| :---             | :---               |
| `main` (Live)    | :white_check_mark: |
| Older commits    | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability or misconfiguration on [ezzulddin.com](https://ezzulddin.com) or within this repository, please report it responsibly:

1. **Email:** Send details directly to **[izzaldinsamir@gmail.com](mailto:izzaldinsamir@gmail.com)**.
2. **Details to Include:**
   - Type of issue (e.g., XSS, header misconfiguration, sensitive data exposure).
   - Clear steps to reproduce or proof-of-concept.
   - Potential impact.
3. **Response Timeline:** Reports are acknowledged within **48 hours**, followed by remediation and deployment to the Cloudflare Pages edge.

Please do not open public GitHub issues for undisclosed security vulnerabilities.
